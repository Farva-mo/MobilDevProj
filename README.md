# MobilDevProj

A group trip planner for Android.

Planning a weekend away with friends? One person (the host) creates a trip with a description and the total cost, then invites everyone else. Invitees confirm in the app whether they are going, and the cost is split evenly between everyone who confirms, host included. Everyone can see who is officially going and how much the trip costs per person. Paying is an honor system: each person marks themselves as paid or not.

**Example:** a $100 trip with the host and 3 confirmed friends is 4 people, so $25 each.

Built with Java and XML layouts (Material 3).
